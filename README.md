# 🍽️ Food Delivery Analytics using SQL Server & Power BI

## 📌 Project Overview

This project is an end-to-end Food Delivery Analytics solution built using SQL Server and Power BI. The project analyzes customer orders, restaurant performance, sales trends, and delivery information to generate business insights through an interactive dashboard.

---

## 🛠️ Tools Used

- SQL Server
- Power BI
- DAX

---

## 📂 Dataset

The project contains five tables:

- Customers
- Orders
- Restaurants
- Riders
- Deliveries
